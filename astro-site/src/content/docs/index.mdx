<Band density="compact">
  <SectionHeader eyebrow="The AI SDK" title="Compose the capabilities your application needs." description="Reusable modules connect inference, data capture, connectivity and the system services around them." />

  NSX resolves the modules you select and their required dependencies, then integrates
  them into your CMake project. HAL, BSP and device support provide the hardware foundation.
  Start with a bare-metal application, or add the FreeRTOS module when you need tasks.

  <CardGrid columns={3} equalize>
    <LinkCard title="Compose with modules" href="/neuralspotx/guides/modules/using-modules/">Find reusable capabilities, add them to your app and lock the resolved dependency set.</LinkCard>
    <LinkCard title="Choose your toolchain" href="/neuralspotx/guides/system/toolchains/">Use GCC, Arm Toolchain for Embedded (ATfE) or Arm Compiler for Embedded (ACFE). Check the target declarations and validation status in the toolchain guide.</LinkCard>
    <LinkCard title="Bare metal or FreeRTOS" href="/neuralspotx/guides/examples/freertos_blinky/">Keep a simple application loop or build on FreeRTOS tasks. The example shows the module and initialization steps.</LinkCard>
  </CardGrid>
</Band>

<Band density="compact">
  <SectionHeader eyebrow="Start here" title="From setup to running firmware." description="Follow the steps, or select one to replay its terminal example." />
  <JourneyWalkthrough stages={transcripts.stages} />
  Abbreviated examples: install with `uv tool install neuralspotx`, check with `nsx doctor`,
  create with `nsx create-app`, then `nsx build`, `nsx flash` and `nsx view`.
  Hardware output is illustrative. Follow [Getting started](/neuralspotx/getting-started/) for the complete instructions.
</Band>

<Band tone="muted" density="compact">
  <SectionHeader eyebrow="Modules" title="Find a capability. Add it to your app." description="A familiar dependency workflow, applied to embedded firmware." />

  Once your first app builds, add capabilities through NSX modules. Like pip, Cargo or npm,
  NSX uses named dependencies, manifests and a lockfile, with compatibility checks for your target.

  <CardGrid columns={3} equalize>
    <LinkCard title="1. Find a capability" href="/neuralspotx/modules/catalog/">Search by function, then filter by board or toolchain. Inspect dependencies and declared compatibility.</LinkCard>
    <LinkCard title="2. Add it to your app" href="/neuralspotx/guides/modules/using-modules/">Add a module by name. NSX updates nsx.yml, resolves required dependencies and syncs their sources.</LinkCard>
    <LinkCard title="3. Build and keep the lock" href="/neuralspotx/guides/modules/lock-and-sync/">Build your application and commit nsx.lock to record the resolved source set.</LinkCard>
  </CardGrid>
  <div class="nsx-section-action">
    <CodeBlock variant="terminal" language="bash" label="Inside your app directory" code={`nsx module search audio\nnsx module add nsx-audio\nnsx build`} />
  </div>
</Band>

<Band tone="muted" density="compact">
  <SectionHeader eyebrow="Your project" title="Select modules. Keep control of the build." description="The generated project keeps your sources, board support and dependencies together." />
  <CardGrid columns={3} equalize>
    <LinkCard title="Create an app" href="/neuralspotx/getting-started/first-app/">Start with a board and template. NSX writes your manifest, CMake project and source files, then brings in the board baseline.</LinkCard>
    <LinkCard title="Lock the dependency set" href="/neuralspotx/guides/modules/lock-and-sync/">Record resolved sources and hashes in nsx.lock. Sync the same set on another checkout and export it with nsx sbom.</LinkCard>
    <LinkCard title="Build with CMake" href="/neuralspotx/guides/system/toolchains/">Use CMake and Ninja with the toolchain declared for your target. Your application remains an editable firmware project.</LinkCard>
  </CardGrid>
  After [checking your environment](/neuralspotx/getting-started/doctor/), follow
  [build, flash and view](/neuralspotx/guides/apps/build-flash-view/) to run the app.
  [App layout](/neuralspotx/guides/apps/app-layout/) explains which files you own and which
  NSX regenerates.
</Band>

  families, declaring 3 toolchains between them, and this repository carries 10 example

<Band density="compact">
  <Callout title="NSX is Beta, supported for evaluation" tone="important">
    NSX is Beta and is supported for evaluation: use it for bring-up, profiling,
    validation and demos. Production support is not committed before 1.0. Every name
    exported from the `neuralspotx` Python package carries the **Provisional** stability
    tier: the name is public and supported, and it may still change before 1.0. Pin an
    exact version of `neuralspotx` anywhere it is a dependency of something you ship, and
    record that version alongside the artifacts it produced. See
    [Releases and versioning](/neuralspotx/reference/releases/) for how versions are
    numbered and what pins separately from the CLI.
